## Executive Summary
NeuroPilot represents a monumental evolution in developer tooling. Rather than forcing human minds to adapt to the linear boundaries of legacy calendar systems, NeuroPilot operates as a cognitive co-processor that wraps around the developer's biological state. ## 1. The Burning Problem Statement
The software industry suffers from a systemic structural flaw: Static Calendar Rigidity. Modern project managers treat human cognitive capacity as an infinite linear buffer. Engineers are subjected to back-to-back synchronous meetings and over-allocated focus blocks, resulting in:

* **The Overload Cascade:** Continuous high-intensity work triggers micro-stress spikes. High fatigue compromises code quality, leading to compounding syntax bugs and technical debt, ultimately causing developer burnout and sudden roadmap slippages.
* **Milestone Blind Spots:** Current planning platforms (such as Jira or Linear) lack context awareness of the engineers' cognitive health. Slip probabilities remain hidden until the deadline has already passed, triggering panic, rushed commits, and project failures.

## 2. The Solution: Adaptive Cognitive Guardrails
NeuroPilot resolves this bottleneck by implementing three core autonomic layers that bridge biometrics, roadmap planning, and intelligent schedule healing:

### I. Predictive Sentry Radar
Our proprietary telemetry engine actively aggregates developer focus metrics, meeting frequencies, and scope drift. Using Monte-Carlo algorithms, the Risk Radar identifies slip probabilities for deliverables, offering early visual warnings before deadlines fail.

### II. Gemini Autonomic Schedule Repair
When stress indicators surpass threshold levels, our Autonomic Repair Engine triggers. It parses calendar collisions, reschedules low-priority items, places screen-free mindfulness buffers, and optimizes deep work blocks based on personalized circadian focus cycles.

### III. Neural Co-Processor Advisor
An intelligent chatbot co-processor powered by advanced LLM memory context. It serves as an on-demand strategic partner, providing developer-first stress mitigations, code prioritization advice, and bio-break reminders.

* **Biometric Simulation Engine:** In-app active telemetry controller enabling judges to trigger warning states and witness real-time scheduling repair behaviors.

## 🚀 Getting Started

Follow these steps to run the NeuroPilot app locally on your machine.

### Prerequisites
- [Node.js](https://nodejs.org/) installed on your machine.

### Installation & Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Configure Environment Variables:**
   Create a `.env.local` file in the root directory (you can copy `.env.example`) and add your Gemini API Key:
   ```env
   GEMINI_API_KEY="your_gemini_api_key_here"
   ```

3. **Run the Development Server:**
   Start the application locally:
   ```bash
   npm run dev
   ```
   The app will be available at `http://localhost:3000`.
